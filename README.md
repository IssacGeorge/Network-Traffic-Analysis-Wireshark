# Network Traffic Analysis Using Wireshark

## 📌 Project Overview
This project explores network traffic analysis using Wireshark in a virtual lab environment. The objective was to understand network communication and analyze packet-level activity generated during network testing.

## 🎯 Objectives
- Analyze ICMP requests and replies.
- Observe Nmap scanning activity and TCP responses.
- Examine TCP SYN traffic in a controlled lab.
- Understand packet behavior and network communication.

## 🛠️ Tools Used
- Wireshark
- Kali Linux
- Ubuntu Linux
- Nmap
- hping3
- Oracle VirtualBox

## 🧪 Lab Environment
A virtual lab using Kali Linux and Ubuntu Linux was used to generate and analyze network traffic.

## 🔍 Activities Performed
1. **ICMP Analysis:** Examined ping requests and replies.
2. **Nmap Traffic Analysis:** Observed TCP packets and responses during network scanning.
3. **TCP SYN Traffic Analysis:** Investigated SYN packet patterns generated in the lab.

## 💡 Key Learnings
- Understanding TCP/IP and ICMP communication.
- Identifying TCP flags and packet patterns in Wireshark.
- Observing network scanning activity.
- Analyzing network traffic in a virtual environment.
